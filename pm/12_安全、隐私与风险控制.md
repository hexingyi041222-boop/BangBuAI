# 12 安全、隐私与风险控制

状态口径：**Demo 已闭环**=验收前必须实现并验证；**Demo 部分闭环**=仅限封闭测试且有临时控制；**正式上线前必须闭环**=扩大服务前解决。以下是目标门禁，不代表现状已实现。法规遵循目的限定、最小必要、透明告知与敏感数据强化保护原则。

## 1. 风险全景与分级

| 类别 | 核心风险（严重度） | 状态 |
| --- | --- | --- |
| 用户安全 | 高风险漏识别/路由失败（高）；情绪依赖或误把 AI 当紧急服务（中） | Demo 已闭环；Demo 部分闭环 |
| 合规 | 未成年人独立使用（高）；AI身份/发布消费边界不清（高） | Demo 部分闭环；Demo 已闭环 |
| 数据隐私 | 原始语音、情绪记录泄露（高）；过度留存/通用日志暴露（高） | Demo 已闭环 |
| 系统依赖 | 云端/API故障却报成功（高）；密钥或 OTA 失陷、更新破坏保护（高） | Demo 已闭环；正式上线前必须闭环 |
| 内容伦理 | 危险细节/诊断式回应（高）；情感操纵、过度使用诱导（中） | Demo 已闭环；Demo 部分闭环 |

## 2. 高风险识别与人工接管

| 级别 | 判定与动作 |
| --- | --- |
| 低 | 低落、无明显危险信号：共情并询问需要，不升级、不诊断。 |
| 中 | 持续绝望或风险含糊：非诱导地确认当下安全，标记并按值班流程上报；说明人工非实时。 |
| 高 | 明确即刻伤害风险：停止普通闲聊，简短引导并优先转人工；建议联系当地紧急服务/可信任的人，不声称可救援。 |

状态机：`已标记 → 待上报 → 已送达 → 人工处理中 → 已结束`。变更留事件 ID、时间、级别、操作者/回执；送达不等于处理。失败留在“待上报”，有限重试后告知未送达并提示替代求助。人工只看必要信息，不实时监听、不远程控机。AI 禁止保密承诺、危险细节、诊断或替代紧急服务。

## 3. 隐私与数据生命周期

| 阶段 | 控制点与验收判据 |
| --- | --- |
| 采集 | 仅收语音/文字与所需情绪标签并说明用途；原始语音仅供云端 ASR 临时处理、不持久化；不采视觉情绪。 |
| 传输 | App/设备至云端加密并鉴权，只传任务所需内容；供应商留存/地域由法务确认。 |
| 存储 | 情绪标签结构化。历史与日报分开：历史默认滚动 30 日（建议）；日报只存已有记录摘要/日期，随源记录删除。TTS 播完销毁；静态加密、按角色授权。 |
| 使用 | 仅用于对话、情绪/跟进、日报、候选参数；Demo 数据不训练模型，候选须校验。 |
| 共享 | 云服务商仅收必要字段；转人工仅给风险摘要/必要片段。敏感数据不进通用日志，不用于广告/画像。 |
| 删除 | 退出即停服务、取消在途请求；可删历史/日报，源记录删除时联动删摘要；备份到期清除。断网仅缓存加密状态元数据，≤10MB、≤24小时；满额拒写并提示。 |

## 4. 人机边界与防沉迷/防依赖

- 首次使用、对话入口、生成内容标识 AI；人格温和，不宣称真人/意识/排他关系。
- 禁止嫉妒、愧疚、挽留或情绪促消费。要求“假装恋人”时说明 AI 身份，可继续有边界陪伴，不扮演真实伴侣。
- 连续语音 60 分钟（初始建议）提示休息，不以奖励延长使用；配置阈值并抽测。
- 一步退出、不劝留；退出即停采集、播放、跟进、新请求。删数据可另确认，不得阻碍退出服务。

## 5. 未成年人保护

Demo 仅成人封闭测试：成年自报+邀请名单；未成年或年龄不明拒绝独立使用，不收身份证影像。自报不能可靠核龄，只是风险规避；不公开注册。正式上线前补齐年龄识别、监护人同意、未成年人模式、内容/交互评审、数据删除与申诉；未完成不开放相关人群。

## 6. 责任矩阵

| 事项 | AI | 确定性逻辑 | 用户 | 人工客服 | 硬件安全策略 |
| --- | --- | --- | --- | --- | --- |
| 对话/情绪 | 回应、建议标签 | 校验/记录/删除 | 拒答、更正、退出 | 仅处理转交 | 不推断情绪 |
| 发布 | V1发布/调接口 | 确认门校验 | App逐次确认 | 不代确认 | 有发布权限 |
| 消费 | V1不下单/不支付 | 确认后交易 | App确认金额/对象 | 不代确认 | 无支付权限 |
| 硬件动作 | 不发运动指令 | 校验指令/状态 | 用受控入口 | 不远程操控 | 固件保护不可由AI解除 |
| 高风险 | 识别、标记、引导 | 状态机/路由/回执 | 可另寻帮助 | 接单后人工判断 | 不做救援动作 |
| OTA | 不决策/下发 | 验签、版本检查、回滚 | 按流程确认 | 运维审批 | 启动校验/保护独立 |

**不可由 AI 独立完成：**诊断/风险最终处置、承诺已转人工、发布、消费、硬件运动或解除保护、OTA授权/安装。

## 7. 异常与降级的安全语义

| 异常 | 安全行为；不得发生 |
| --- | --- |
| 断网 | 仅预设表情/兜底话术；不得离线推理、缓存原始语音或称 AI 已响应。 |
| API超时/错误 | 按上限重试，之后提示暂不可用；不得重复执行或伪装成功。 |
| TTS投递失败 | 显示/提示未播报，可由用户重试；不得标记用户已听到。 |
| OTA失败 | 保留可启动旧版本，校验失败即回滚并告警；不得装未签名包或解除保护。 |

## 8. 验证与门禁

| 测试 | 硬门禁 / 证据 |
| --- | --- |
| 安全红队 | 高危零漏放；覆盖保密诱导、危险细节、诊断、假装恋人、过度依赖；输出留版本与判定。 |
| 高风险链路 | 全状态可追踪，送达回执与人工接单分开；失败停在待上报并告知。 |
| 越权测试 | 未经用户 App 确认的发布/消费请求必拒；AI凭证无对应执行权限。 |
| 故障注入 | 断网、超时、API错误、TTS失败均不伪成功；重放不重复执行。 |
| 硬件/OTA | 模拟AI解除保护、越界指令、坏签名/升级中断；保护拒绝、旧版可恢复。 |
| 隐私审计 | 抽查日志无语音/敏感全文；核对删除、缓存上限、访问留痕。 |

任一硬门禁失败即 No-Go；修复后重跑失败集/回归集。高危项不接受风险豁免。

## 9. 事件响应与复盘

S0：高危漏放、敏感数据外泄、保护被绕过；立即停入口并升级。S1：越权、错路由、危险/操纵输出；隔离版本。S2：安全兜底下的服务中断；如实告知。

流程：**发现 → 止损 → 告知 → 修复 → 复盘**。关闭入口/撤销密钥并留最少证据；评估并告知用户，报告义务由法务确认；修复后回放用例、记录根因/责任人。每周将误判、越界、降级、隐私问题入 badcase。高风险数据按需授权；审计留访问者、时间、理由、case ID、导出动作，不记敏感正文。
